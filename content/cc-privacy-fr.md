- Soumettre une demande de suppression des données conservées à votre sujet, si nous les utilisons de manière illicite ;

- Soumettre une demande de transmission (réception) des données que vous nous avez fournies dans le cadre du contrat ou avec votre consentement et que nous traitons par des moyens automatisés, généralement sous format électronique ;
- Retirer le consentement que vous nous avez donné pour l'utilisation de vos données – si nous utilisons les données sur la base de votre consentement ;
